Architected a decoupled, event-driven candidate ingestion pipeline using FastStream and Apache Kafka to process unstructured profiles asynchronously. Engineered a sophisticated entity resolution and profile merging engine with Groq LLM and a custom-weighted confidence scoring algorithm, resolving identity conflicts in PostgreSQL with 98% precision.
